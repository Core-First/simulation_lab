Red-Black Insert Algorithm (Simplified)

function insert(node, val)
if node == null:
  return new Node(val, color=RED)
if val < node.val:
  node.left = insert(node.left, val)
else if val > node.val:
  node.right = insert(node.right, val)
if node.left is RED and node.right is RED:
  // uncle is red: recolor
  node.left.color = BLACK
  node.right.color = BLACK
if imbalance detected:
  // perform single or double rotation
  return rotate(node)
if node is root:
  node.color = BLACK
return node

Red-Black Tree Rules

RB Properties:
1. Every node is RED or BLACK
2. Root is always BLACK
3. Leaves (nil) are BLACK
4. No two RED nodes can be adjacent
5. All paths have same # of BLACK nodes

1def insert(node, val):

3        return Node(val, color=RED)  # new nodes always RED

11        node.left.color = BLACK
12        node.right.color = BLACK
13        node.color = RED # propagate red up
14    # Fix: RED-RED violation → rotate

Red-Black Insertion Rules

Note: This is a simplified educational representation. Full Red-Black trees require more detailed case analysis. The key insight is that colour-based balancing gives O(log n) guarantees while requiring fewer rotations than AVL on average.
Trace ready.

● Every node is RED or BLACK

● Root is always BLACK

● Leaves (nil) are BLACK

● No two RED nodes can be adjacent

● All root→leaf paths have equal BLACK-node count

  • New nodes: Always inserted as RED (to avoid disturbing black-height).
  • Recolor: If uncle is RED, flip parent and uncle to BLACK, grandparent to RED — then check grandparent.
  • Rotate: If uncle is BLACK and there's a RED-RED parent-child, perform a rotation (like AVL) plus recoloring.
  • Root fix: Always color the root BLACK after all adjustments.

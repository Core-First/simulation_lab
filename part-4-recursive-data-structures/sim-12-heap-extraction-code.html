Heap Extraction — SiftDown

Key Insight: We can't simply remove the root — that would leave a gap. Instead, move the last element to the root (preserving the complete-tree shape) and sift it down to its correct position, restoring heap order.
Trace ready.
  • Save root: Store heap[0] — this is the minimum value to return.
  • Move last to root: Copy the last element to index 0 to fill the gap.
  • Pop last: Remove the now-duplicate last element.
  • SiftDown: Compare the new root with its children. Swap with the smaller child if needed. Repeat until no swap is needed or a leaf is reached.
  • Time complexity: O(log n) — at most one swap per level.

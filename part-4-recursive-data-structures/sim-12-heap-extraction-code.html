Extracting minimum and restoring heap order

Extract-Min & Heapify Algorithm

function extractMin()
if heap.length === 0 return null
root = heap[0] // Save minimum value
heap[0] = heap[heap.length - 1] // Move last to root
heap.pop() // Remove last element
siftDown(0) // Restore heap property
return root
function siftDown(i)
while i has children:
left = 2*i + 1, right = 2*i + 2
smallest = i
if left < n and heap[left] < heap[smallest]:
smallest = left
if right < n and heap[right] < heap[smallest]:
smallest = right
if smallest ≠ i:
swap(heap[i], heap[smallest])
i = smallest
else break

Understanding Extraction

Key Insight: To extract the minimum efficiently, we remove the root and restore the heap property by moving the last element to the root and sifting it down.

Extraction Steps:
1. Return the root (minimum value)
2. Move the last element to the root
3. Remove the last element from the array
4. Sift down from the root

SiftDown Process:
- Compare node with its children
- Swap with the smaller child if necessary
- Continue until heap property is restored
- Time complexity: O(log n)

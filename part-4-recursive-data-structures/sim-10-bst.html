Theory & Concepts

What is a BST?

A Binary Search Tree is a recursive data structure where each node stores a value and has at most two children — a left subtree and a right subtree.

The BST Property

For every node N:

  • All values in the left subtree are less than N
  • All values in the right subtree are greater than N
  • Both subtrees are themselves valid BSTs

Core Operations

  • Insert — recursively descend until an empty spot is found
  • Search — compare at each node; go left or right accordingly
  • Delete — three cases: leaf, one child, two children
  • Traversal — In-order gives sorted output

Traversal Orders

  • In-order (L → Root → R) — sorted ascending
  • Pre-order (Root → L → R) — useful for copying
  • Post-order (L → R → Root) — useful for deletion

Time Complexity

Worst case occurs when the tree is completely unbalanced (e.g. sorted input).

Theory & Concepts

What is a Heap?

A heap is a complete binary tree stored as an array where every parent is smaller (min-heap) or larger (max-heap) than its children. The root is always the extreme value.

Array Representation

For a node at index i:

  • Parent: (i−1) / 2
  • Left child: 2i + 1
  • Right child: 2i + 2

Core Operations

  • Insert — append then sift up to restore heap property
  • Extract Min — remove root, move last to root, sift down
  • Peek — read heap[0] without removing

Priority Queues

Heaps are the ideal backing structure for a priority queue — elements are dequeued in priority order. Used in Dijkstra's shortest path, A* search, and OS scheduling.

Heap & Priority Queue

A complete binary tree satisfying the heap property — enabling O(log n) insertion and O(log n) extraction of the minimum/maximum element, powering schedulers, Dijkstra's algorithm, and more.

Theory & Concepts

Heap Property

A Max-Heap: parent ≥ children at every node. A Min-Heap: parent ≤ children. The root is always the extreme value.

Structure Property

  • A complete binary tree — all levels filled left to right
  • Stored efficiently as a flat array
  • Parent of node i: ⌊(i–1)/2⌋
  • Left child of i: 2i + 1
  • Right child of i: 2i + 2

Core Operations

  • Insert — append + bubble-up (sift-up)
  • Extract-Max/Min — swap root & last, pop, bubble-down
  • Peek — O(1) access to root
  • Heapify — build from unsorted array in O(n)

Applications

  • Dijkstra's shortest path
  • A* pathfinding
  • CPU / task schedulers
  • Huffman encoding
  • k-th largest element
  • Heap Sort algorithm

Min-Heap

Parent ≤ children — smallest at root

A Min-Heap places the minimum element at index 0. Fundamental in Dijkstra's algorithm, A* search, and any greedy algorithm needing the smallest item next.

Insert 5 into Min-Heap [2, 4, 8, 6]:

Step 1: Append    →  [2, 4, 8, 6, 5]
Step 2: Compare 5 < parent(4)?  No
Step 3: Compare 5 < parent(2)?  No → Done

Result: [2, 4, 8, 6, 5] ✓
Min at root O(log n) insert

Priority Queue

Abstract data type built on heaps

A Priority Queue is an abstract data type that dequeues elements in priority order rather than insertion order. Heaps are its most efficient implementation.

Heapify in O(n)

Build a heap from any array

Naively inserting n elements takes O(n log n). But Build-Heap starts from the last non-leaf and calls sift-down on every node — achieving O(n) total time.

def build_max_heap(arr):
    n = len(arr)
    # Start from last non-leaf: n//2 - 1
    for i in range(n // 2 - 1, -1, -1):
        sift_down(arr, n, i)

Min-Heap Properties

A min-heap is a complete binary tree where each parent is smaller than or equal to its children. The minimum element is always at the root.

Key Features:

  • Parent at index i: left child at 2i+1, right at 2i+2
  • Efficient minimum extraction: O(log n)
  • Used in priority queues and heap sort

Priority Queues

Heaps are ideal for implementing priority queues where elements with higher priority are accessed first. Used in algorithms like Dijkstra's shortest path and A* search.

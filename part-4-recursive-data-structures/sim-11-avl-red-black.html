AVL Trees

An AVL tree is a self-balancing BST where the height difference between left and right subtrees is at most 1 (the balance factor).

Key Properties:

  • Balance factor: height(left) − height(right) must be in {−1, 0, +1}
  • Rotations restore balance after insertions/deletions
  • Four rotation types: LL, LR, RR, RL

Red-Black Trees

A Red-Black tree is a BST with color attributes (red/black) that maintain near-balance through relaxed constraints.

Rules:

  • Every node is colored red or black
  • Root is always black
  • Leaves (nil) are black
  • Red nodes cannot have red children
  • All paths from node to leaves have equal black-node count

Simulation area: visual representation of the selected tree. Click and drag (or touch) to pan; use insert controls on the right to add values and experiment.

How to use this simulation

This interactive sim demonstrates how AVL and Red-Black trees keep binary search trees balanced after insertions. Steps:

  1. Pick AVL or Red-Black using buttons above the canvas.
  2. Enter a value on the right and press Insert to add it.
  3. Press Run Trace to highlight code steps in sequence.
  4. Use presets from the left sidebar to load example trees.

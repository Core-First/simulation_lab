Theory & Concepts

Why Balanced Trees?

A plain BST degrades to O(n) when values are inserted in sorted order. Self-balancing trees enforce structural constraints so height stays O(log n) at all times.

AVL Trees

An AVL tree keeps the balance factor of every node in {−1, 0, +1}:

  • BF = height(left) − height(right)
  • |BF| > 1 triggers a rotation to restore balance
  • Four rotation types: LL, LR, RR, RL

AVL Operations

  • Insert — BST insert then rebalance on unwind
  • Delete — remove node, rebalance ancestors

Red-Black Trees

A Red-Black tree uses color attributes to maintain near-balance with fewer rotations than AVL:

  • Every node is RED or BLACK
  • Root is always BLACK
  • No two RED nodes can be adjacent
  • All paths to leaves have equal black-node count
  • Insertion trace — see recoloring & rotations

AVL Time Complexity

SearchO(log n)O(log n)

Guaranteed O(log n) unlike plain BST.

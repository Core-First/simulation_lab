AVL Tree & Red-Black Tree

Self-balancing Binary Search Trees that guarantee O(log n) worst-case performance for all operations — eliminating the O(n) degradation of unbalanced BSTs.

Theory & Concepts

Why Self-Balancing?

A standard BST can degrade into a linked list (O(n) height) with sorted insertions. Self-balancing trees maintain height as O(log n) automatically.

AVL Tree Rules

  • Every node stores a balance factor = height(right) – height(left)
  • Balance factor must be –1, 0, or +1 at all times
  • Violation triggers one or two rotations
  • Height guaranteed ≤ 1.44 × log₂(n+2)

AVL Rotations

  • Left Rotate — right-heavy imbalance
  • Right Rotate — left-heavy imbalance
  • Left-Right — left child is right-heavy
  • Right-Left — right child is left-heavy

Red-Black Rules

  • Every node is Red or Black
  • Root is always Black
  • Red node cannot have Red children
  • All paths to leaves have equal Black height
  • NULL leaves are considered Black

Time Complexity

OpAVLR-B
SearchO(log n)O(log n)
InsertO(log n)O(log n)

When to Use?

  • AVL — more rigid balance, faster lookups
  • Red-Black — fewer rotations, faster inserts/deletes
  • R-B used in: Linux scheduler, Java TreeMap, C++ STL map

AVL Tree

Height-balanced BST (Adelson-Velsky & Landis, 1962)

An AVL tree maintains a balance factor at each node. After every insertion or deletion, the tree checks for imbalance and restores it via rotations.

Before (Left-Heavy):    After Right Rotate:

      30 [BF=-2]            20 [BF=0]
     /                   /    \
   20 [BF=-1]          10     30
   /
  10
Height ≤ 1.44·log n Strict balance O(log n) all ops

Red-Black Tree

Relaxed-balance BST (Bayer, 1972)

Red-Black trees use node colouring with 5 invariants to maintain approximate balance. They allow slightly more height variance but require fewer rotations than AVL.

Example R-B Tree:

         10B
        /     \
      5R       20R
     / \      /  \
   3B   7B  15B  25B
Red/Black nodes Fewer rotations Used in OS kernels

Rotation Cases

Four imbalance patterns

AVL uses 4 rotation patterns to restore balance after insertions:

  • › LL Case — single right rotation
  • › RR Case — single left rotation
  • › LR Case — left rotate child, then right rotate root
  • › RL Case — right rotate child, then left rotate root
Single rotations: O(1) Double rotations: O(1)

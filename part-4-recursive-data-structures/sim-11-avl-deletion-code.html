Deletion & Rebalancing Algorithm

function delete(node, val)
if node is null return null
if val < node.val: node.left = delete(node.left, val)
else if val > node.val: node.right = delete(node.right, val)
else (found target)
if no children: return null
if one child: return that child
if two children: find inorder successor
node.val = successor.val; delete successor
updateHeight(node)
balance_factor = height(left) - height(right)
if BF > 1 and left.BF ≥ 0: rotateRight(node)
if BF > 1 and left.BF < 0: rotateLeft(left); rotateRight(node)
if BF < -1 and right.BF ≤ 0: rotateLeft(node)
if BF < -1 and right.BF > 0: rotateRight(right); rotateLeft(node)
return node

Understanding Deletion

Key Insight: After deleting a node, AVL trees may become unbalanced. The balance factor helps us identify which rotations to apply to restore the AVL property.
Trace ready.
Three deletion cases:
1. Leaf node: Simply remove it
2. One child: Replace with that child
3. Two children: Find inorder successor, copy its value, then delete the successor

Rebalancing: After deletion (or during recursive unwinding), check the balance factor at each node. Apply single or double rotations as needed.

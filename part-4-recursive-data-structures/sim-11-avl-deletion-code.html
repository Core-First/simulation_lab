AVL Deletion & Rebalancing

Key Insight: After deleting a node, AVL trees may become unbalanced. The balance factor check and rotations on the unwind path restore the AVL property — just like insertion, but potentially at more levels.
Trace ready.
  • Case 1 — Leaf node: Simply return None (remove it).
  • Case 2 — One child: Replace the node with its only child.
  • Case 3 — Two children: Find the in-order successor (smallest in right subtree), copy its value, then delete the successor recursively.
  • Rebalance on unwind: After each recursive return, update the height and check BF. Apply the same four rotation types (LL, LR, RR, RL) as in insertion.

Step-by-step min-heap insertion and extraction

Heap Insert Algorithm

function insert(heap, val)
  heap.push(val)
  siftUp(heap, heap.length - 1)
return heap

SiftUp (Bubble Up)

function siftUp(heap, i)
while i > 0:
  parent = (i - 1) / 2 // integer division
if heap[i] < heap[parent]:
  swap(heap[i], heap[parent])
  i = parent
else: break

Heap Extract (Removal) Algorithm

function extractMin(heap)
if heap is empty: return null
root = heap[0]
heap[0] = heap[heap.length - 1]
heap.pop()
siftDown(heap, 0)
return root

SiftDown (Bubble Down)

function siftDown(heap, i)
while 2*i + 1 < heap.length:
  left = 2*i + 1
  right = 2*i + 2
  smallest = i
if heap[left] < heap[smallest]: smallest = left
if right < heap.length and heap[right] < heap[smallest]: smallest = right
if smallest != i:
  swap(heap[i], heap[smallest])
  i = smallest
else: break
Trace ready.
Key Concepts:
• Parent of node i: (i-1)/2
• Left child: 2i+1 | Right child: 2i+2
• Min-Heap: parent ≤ both children
• Time: Insert O(log n), Extract O(log n)

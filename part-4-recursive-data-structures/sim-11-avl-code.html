How AVL Insertion Works

Balance Factor (BF) = height(left) − height(right)
AVL trees enforce |BF| ≤ 1 at every node. If a BST insertion violates this, one of four rotations restores balance before returning up the call stack.
Trace ready.
  • Step 1 — BST Insert: Recursively descend left or right as in a plain BST.
  • Step 2 — Update Height: On the way back up, recalculate each node's height.
  • Step 3 — Check BF: If |BF| > 1, the subtree is unbalanced.
  • LL rotation: BF > 1 and new value went left-left → single right rotation.
  • RR rotation: BF < −1 and new value went right-right → single left rotation.
  • LR rotation: BF > 1 and new value went left-right → left-rotate child, then right-rotate.
  • RL rotation: BF < −1 and new value went right-left → right-rotate child, then left-rotate.

AVL Insert Algorithm

function insert(node, val)
  if node == null:
    return new Node(val)
if val < node.val:
  node.left = insert(node.left, val)
else if val > node.val:
  node.right = insert(node.right, val)
else:
  return node // duplicate
  updateHeight(node)
bf = height(node.left) - height(node.right)
if bf > 1 and val < node.left.val:
  return rotateRight(node)
if bf > 1 and val > node.left.val:
  node.left = rotateLeft(node.left)
  return rotateRight(node)
if bf < -1 and val > node.right.val:
  return rotateLeft(node)
if bf < -1 and val < node.right.val:
  node.right = rotateRight(node.right)
  return rotateLeft(node)
return node

How Balance Factor Works:
BF = height(left) - height(right)
• BF > 1: Left-heavy (left rotations needed)
• BF < -1: Right-heavy (right rotations needed)
• -1 ≤ BF ≤ 1: Balanced

Algorithm Steps:
1. Recursively insert value (BST property)
2. Update height of current node
3. Calculate balance factor
4. Perform rotations if needed

Rotation Types:
• LL: Left-left imbalance → single right rotation
• LR: Left-right imbalance → left then right rotation
• RR: Right-right imbalance → single left rotation
• RL: Right-left imbalance → right then left rotation

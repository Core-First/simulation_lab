Interactive Hash Table
Algorithm Information

Hashing maps data to a fixed-size table. If two keys hash to the same index, a Collision occurs. This simulator demonstrates resolving collisions via Linear Probing (finding the next empty slot) and Chaining (using linked lists at each slot).

Average Time: O(1) Worst Time: O(n) Space: O(n)

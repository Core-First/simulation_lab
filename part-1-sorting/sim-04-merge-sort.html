Merge Sort

Merge Sort is an efficient, general-purpose, and comparison-based sorting algorithm. Most implementations produce a stable sort. It is a divide-and-conquer algorithm that recursively breaks down a list into several sublists until each sublist consists of a single element and merging those sublists in a manner that results into a sorted list.

✅ Stable ❌ Not In-Place (O(n) space) ❌ Not Adaptive
Complexity
BestO(n log n)
AverageO(n log n)
WorstO(n log n)
SpaceO(n)
How it Works

Merge Sort divides the array in half until pieces have one element (already sorted). It then merges pairs of sub-arrays by always taking the smaller front value from the two sub-arrays. This guarantees O(n log n) performance always, but requires extra memory to hold the merged arrays.

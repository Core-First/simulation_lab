Algorithm Information

Merge Sort is an efficient, general-purpose, and comparison-based sorting algorithm. It is a divide-and-conquer algorithm that recursively breaks down a list into several sublists until each sublist consists of a single element and merging those sublists in a manner that results into a sorted list.

✅ Stable ❌ Not In-Place (O(n) space) ❌ Not Adaptive
Best: O(n log n) Avg: O(n log n) Worst: O(n log n) Space: O(n)

Welcome - Start Here

Merge Sort is a divide-and-conquer algorithm. This simulation shows how the array is split in half, then merged back in sorted order. Use the controls like the earlier sorting labs - no code required.

What You See on Screen
  • Chart: Bars may highlight during split and merge phases.
  • Stats: Comparisons and merge steps (pass/depth counters depend on this sim).
  • Controls: Same as other Part 1 pages - Size, Speed, Run, Step, Reset, New.
  • Info panel: Scroll down on mobile to read complexity and when to use merge sort.
Your First Run
  1. Start with Size 16 (powers of two are easy to follow).
  2. Click Run ▶ and notice the array breaking into smaller pieces, then combining.
  3. Use Step to see each comparison during a merge.
  4. Compare with Quick Sort (next sim) after you understand splitting and merging.
Controls Explained
  • Size / Speed / Order / Custom / New: Same behaviour as Bubble and Selection sorts.
  • ☰ menu: Open the sidebar to pick another simulation.
  • Code tab: Shows merge sort pseudocode for your current array.
Colour Legend (Merge Sort)
  • Blue - general / unsorted context
  • Purple - active merge segment
  • Light blue - comparing two values during merge
  • Green - value placed in merged result

How Merge Sort Works

Merge Sort splits the array in half until pieces have one element (already sorted), then merges pairs by always taking the smaller front value from two sub-arrays. It always runs in O(n log n) but needs extra memory O(n).

Complexity
BestO(n log n)
AverageO(n log n)
WorstO(n log n)
SpaceO(n)
Properties

✅ Stable   ❌ Not in-place (O(n) space needed)   ❌ Not adaptive   ✅ Guaranteed O(n log n) always

Best Used When

Ideal when stability is required, extra memory is acceptable, and guaranteed worst-case performance is needed (e.g. external sorting where data won't fit in RAM).

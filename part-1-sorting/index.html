Sorting Algorithms

Master the fundamentals of algorithmic sorting. Compare basic quadratic sorts (Bubble, Selection, Insertion) against advanced divide-and-conquer sorts (Merge, Quick) using interactive step-by-step visualisations.

New here? How to use Part 1

This lab has five interactive sorting pages. Each one animates an algorithm step by step - you only need a web browser.

  1. Pick a simulation below (start with Bubble Sort if you are new to sorting).
  2. On the simulation page, read Info on the right (on a phone, scroll down past the chart to find it).
  3. Set Size and click Run ▶. Use Step to go slowly, Reset to try again.
  4. Use the ☰ menu (top-left) to switch between sorts or return here.
  5. Tap Dark Mode if you prefer a light background - your choice is remembered.

Bubble Sort

Larger elements bubble to the top. The simplest comparison sort, useful for educational purposes and demonstrating the early-exit adaptive optimisation.

O(n²) Stable In-place

Selection Sort

Finds the minimum element and swaps it into the sorted region. Makes the mathematical minimum number of swaps (n-1) of any comparison sort.

O(n²) Unstable In-place

Insertion Sort

Builds the sorted array one element at a time, just like sorting a hand of playing cards. Highly efficient for small or nearly-sorted datasets.

O(n²) Adaptive Stable

Merge Sort

A divide-and-conquer algorithm that recursively splits the array and merges sorted halves. Guarantees O(n log n) performance at the cost of O(n) memory.

O(n log n) O(n) Space Stable

Quick Sort

Partitions the array around a pivot. The fastest general-purpose sorting algorithm in practice due to a highly optimised inner loop and excellent cache locality.

O(n log n) avg Unstable In-place

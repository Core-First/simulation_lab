Insertion Sort

Insertion Sort is a simple sorting algorithm that builds the final sorted array one item at a time. It is much less efficient on large lists than more advanced algorithms such as Quick Sort or Merge Sort, but provides key benefits for small or nearly sorted lists.

✅ Stable ✅ In-Place ✅ Adaptive (O(n) best case)
Complexity
BestO(n)
AverageO(n²)
WorstO(n²)
SpaceO(1)
How it Works

Insertion Sort iterates, consuming one input element each repetition, and growing a sorted output list. At each iteration, insertion sort removes one element from the input data, finds the location it belongs within the sorted list, and inserts it there. It minimizes movements for nearly sorted inputs.

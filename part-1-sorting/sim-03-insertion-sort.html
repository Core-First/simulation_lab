Welcome - Start Here

This page is an interactive lesson. Bars represent numbers; you control the sort with the buttons below the chart. No programming experience needed.

What You See on Screen
  • Chart: Vertical bars = values in the array.
  • Stats row: Live comparison/swap counts and timer.
  • Control bar: Change data and playback.
  • Info panel: On phones, scroll down after the chart to read everything - including sections at the very bottom.
Your First Run
  1. Choose a small Size (about 10) first.
  2. Click Run ▶ - watch the purple key move and yellow bars shift left.
  3. Try Order → Nearly Sorted to see fewer moves (insertion sort is fast on almost-sorted data).
  4. Use Step after Pause to study one shift at a time.
Controls Explained
  • Size / Speed: How many bars and how fast they animate.
  • Order / Custom / New: Pick preset data, type 8, 3, 15, 1 with ✓, or shuffle again.
  • ☰ menu: Navigate to other sorts or lab home.
  • Dark Mode: Switch appearance (saved locally).
Colour Legend (Insertion Sort)
  • Blue - not yet placed in the sorted region
  • Purple - current key being inserted
  • Yellow - values shifting right to make space
  • Green - sorted prefix (left side)
Right Panel Tabs
  • Info - Scroll for the full guide and complexity table.
  • Code - Example code for your array.
  • AI - Learning help in plain language.
How Insertion Sort Works

Insertion Sort grows a sorted region on the left. It takes the next value (the key), compares it with sorted neighbours, and shifts larger values one step right until the key fits - like sorting playing cards in your hand.

Complexity
BestO(n)
AverageO(n²)
WorstO(n²)
SpaceO(1)
Properties

✅ Stable   ✅ In-place   ✅ Adaptive (O(n) on nearly-sorted)   ✅ Online (can sort as data arrives)

Best Used When

Excellent for small arrays (<32 elements) and nearly-sorted data. Used as the base case inside Timsort and Introsort.

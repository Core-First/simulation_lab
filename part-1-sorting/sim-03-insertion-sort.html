Algorithm Information

Insertion Sort is a simple sorting algorithm that builds the final sorted array one item at a time. It iterates, consuming one input element each repetition, and growing a sorted output list.

✅ Stable ✅ In-Place ✅ Adaptive (O(n) best case)
Best: O(n) Avg: O(n²) Worst: O(n²) Space: O(1)

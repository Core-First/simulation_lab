Welcome - Start Here

This page is an interactive lesson. Each bar is a number; taller means larger. No coding required - use the buttons under the chart to control the simulation.

What You See on Screen
  • Chart: The array as vertical bars.
  • Stats row: Comparisons, swaps, pass count, and timer.
  • Control bar: Size, speed, array type, and playback buttons.
  • This panel (Info / Code / AI): On mobile, scroll down past the chart to read the full guide and reach complexity notes at the bottom.
Your First Run
  1. Set Size to 8–15 for an easier first view.
  2. Click Run ▶ and watch purple (boundary), yellow (scan), and light red (current minimum).
  3. Use Pause + Step to go one comparison at a time.
  4. Reset restores the same array; New shuffles with your current settings.
  5. Try the AI tab for quick answers to common questions.
Controls Explained
  • Size / Speed: Bar count (5–60) and animation speed (1–10).
  • Order: Random, nearly sorted, reversed, or sorted input.
  • Custom + ✓: Your own list, e.g. 45, 12, 67, 3.
  • ☰ menu: Switch simulations or return to the sorting lab home.
  • Dark Mode: Light/dark theme toggle.
Colour Legend (Selection Sort)
  • Blue - unsorted region
  • Purple - boundary between sorted (left) and unsorted (right)
  • Yellow - element currently being scanned
  • Light red - smallest value found so far in this pass
  • Green - final sorted position
Right Panel Tabs
  • Info - Full guide (scroll to the end on small screens).
  • Code - Pseudocode for your current array.
  • AI - Ask questions or tap suggestion chips.
Scrolling this guide

Laptop/desktop: Scroll inside the Info panel (right) with your wheel or trackpad.
Phone/tablet: Scroll the page down past the chart to read Properties and Best Used When.

How Selection Sort Works

Selection Sort splits the array into a sorted region (left) and unsorted region (right). Each pass scans the unsorted part for the minimum, then swaps it into the first unsorted slot. The sorted region grows by one element per pass.

Complexity
BestO(n²)
AverageO(n²)
WorstO(n²)
SpaceO(1)
Properties

❌ Not stable   ✅ In-place   ❌ Not adaptive - always O(n²) comparisons regardless of input

Best Used When

Swapping is expensive (e.g., writing to flash memory). Makes exactly n−1 swaps - the minimum possible for any comparison sort.

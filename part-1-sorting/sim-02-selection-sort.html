Selection Sort

Selection Sort divides the input list into two parts: a sorted sublist of items which is built up from left to right at the front, and a sublist of the remaining unsorted items. The algorithm repeatedly finds the smallest element from the unsorted sublist and swaps it with the leftmost unsorted element.

❌ Unstable ✅ In-Place ❌ Non-Adaptive
Complexity
BestO(n²)
AverageO(n²)
WorstO(n²)
SpaceO(1)
How it Works

Selection Sort scans the unsorted portion of the array to find the minimum value. Once found, this minimum value is swapped with the element at the beginning of the unsorted segment, moving the boundary of the sorted segment one step forward. It performs exactly n-1 swaps.

Welcome - Start Here

This page is an interactive lesson. Each bar is a number; the taller the bar, the larger the value. You do not need to install anything or write code - just use the buttons below the chart.

What You See on Screen
  • Chart (centre): The array shown as vertical bars.
  • Stats row (above chart): Comparisons, swaps, pass number, and elapsed time.
  • Control bar (below chart): Change array size, speed, and playback.
  • Info / Code / AI tabs (this panel): On a phone or tablet, scroll down past the chart to read the full guide - including complexity and tips at the bottom.
Your First Run
  1. Set Size to about 8–15 if this is your first time (fewer bars are easier to follow).
  2. Click Run ▶ and watch the animation.
  3. Press Pause to freeze, then Step ▶▶ to move one action at a time.
  4. Click Reset to return to the same starting array; click New to generate a different one.
  5. Open the AI tab and tap a suggested question if you want a short explanation.
Controls Explained
  • Size (slider): Number of values in the array (5–60).
  • Speed (slider): Animation speed - 1 is slowest, 10 is fastest.
  • Order (dropdown): Random, nearly sorted, reversed, or already sorted data.
  • Custom + ✓: Type your own numbers separated by commas, e.g. 45, 12, 67, 3, then press the check button.
  • ☰ (top-left): Opens the menu to jump to another sorting simulation or the lab home page.
  • Dark Mode: Toggles light/dark theme (saved in your browser).
Colour Legend (Bubble Sort)
  • Blue - not in final position yet
  • Yellow - two neighbours being compared
  • Red - a swap is happening
  • Green - locked in sorted position
Right Panel Tabs
  • Info - This guide and algorithm notes (scroll to see everything).
  • Code - Sample code that matches your current array.
  • AI - Ask questions; use the chips for common topics.
How Bubble Sort Works

Bubble Sort repeatedly compares adjacent elements and swaps them when they are out of order. Larger values “bubble” toward the end each pass. With early-exit, the algorithm stops as soon as a full pass makes no swaps (useful when the data is already sorted).

Complexity
BestO(n)
AverageO(n²)
WorstO(n²)
SpaceO(1)
Properties

✅ Stable   ✅ In-place   ✅ Adaptive (early-exit)

Best Used When

Educational purposes or nearly-sorted small arrays where the early-exit optimisation makes it O(n).

Bubble Sort

Bubble Sort repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order. The pass through the list is repeated until the list is sorted.

✅ Stable ✅ In-Place ✅ Adaptive (Early-Exit)
Complexity
BestO(n)
AverageO(n²)
WorstO(n²)
SpaceO(1)
How it Works

Adjacent items are compared. If the left item is larger than the right item, they are swapped. With each complete pass, the next largest unsorted element "bubbles" up to its final position at the end of the array. The algorithm exits early if a full pass completes without any swaps.

How to Use the Simulation
  1. Click the Simulation tab to open the canvas.
  2. Set Size (5–60 elements) or type a Custom list of values.
  3. Click Run to watch the animation, or use Step to advance one comparison at a time.
  4. Toggle between Dark Mode and Light Mode via the header button.

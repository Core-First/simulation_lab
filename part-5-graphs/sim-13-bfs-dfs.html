Algorithm Information

BFS (Breadth-First Search) explores neighbors layer by layer using a queue. Best for shortest path in unweighted graphs and level-order traversal.

DFS (Depth-First Search) explores as deep as possible using recursion or a stack. Useful for connectivity, topological sorting, and backtracking problems.

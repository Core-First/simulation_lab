Overview

This section groups interactive visualizations for core graph algorithms used in the ATC SimLab: Breadth-First Search (BFS), Depth-First Search (DFS), and Dijkstra's shortest-path algorithm. Each simulation is a standalone HTML page that uses the shared project helpers in assets/js and the common styles in assets/css.

Algorithms
  • BFS — level-order traversal for unweighted graphs; discovers shortest path in number of edges.
  • DFS — depth-first traversal useful for connectivity, topological order (with modifications), and backtracking.
  • Dijkstra — single-source shortest paths for non-negative weighted graphs.

How to Use
  1. Open a simulation (BFS/DFS or Dijkstra) using the links above.
  2. Use the Generate control to create a random graph.
  3. Choose an algorithm control (BFS / DFS / Run Dijkstra) and start the animation using Play or step through with Step.
  4. Use the AI Assistant panel in each simulation to request hints or explanations; the assistant uses a local static hint generator in assets/js/ai-assistant.js.
Implementation Notes
  • Visual drawing is implemented with the Canvas API in assets/js/visualizer-core.js.
  • Shared utilities (timers, sleep, generators) live in assets/js/utils.js.
  • Each simulation is intentionally standalone (no bundler). Use relative paths to include shared assets.
Run / Test Locally

This is a static site — run a local HTTP server from the repository root to avoid local file restrictions:

python -m http.server 8000

Then open:

  • /part-5-graphs/sim-13-bfs-dfs.html
  • /part-5-graphs/sim-14-dijkstra.html
Limitations & Accessibility
  • Graphs are randomly generated and small (up to 20 nodes) for readability and performance.
  • Dijkstra visualization assumes non-negative weights and highlights distances; very large graphs may be slow on low-end devices.
  • Keyboard navigation and ARIA labels are minimal; consider adding textual step logs for screen readers in future work.
